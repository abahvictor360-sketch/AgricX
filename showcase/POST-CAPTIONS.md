## Upwork / Fiverr / Behance project description

**AgricX: responsive website for an agri-tech brand**

A responsive marketing and e-commerce website for an agricultural drone and precision farming brand. I turned a static design concept into a working 21-page site with scroll animations, deployed on Vercel.

**Scope**
- Home, product catalogue, 7 product detail pages, services and pricing, blog with 6 articles, about, contact, 404
- Responsive layouts for desktop, tablet and mobile
- Scroll animations: word-by-word headline reveals, parallax backgrounds, image reveals, staggered cards, count-up stats, a moving keyword banner
- Interactive features: category filters and search, product gallery, quantity picker and cart counter, accordions, a contact form that checks its fields
- Respects the "reduce motion" accessibility setting, uses semantic HTML, includes SEO meta tags
- All content comes from one data file, so it's easy for the client to update

**Tech:** HTML, CSS, vanilla JavaScript, a Node.js build script, Vercel

**Live:** https://agricx-five.vercel.app
